## Positive notes

- **The producer removal is provably behavior-neutral.** Every surviving `StopParams` literal — `internal/org/verbs.go:360` (`Disband`), `internal/cli/org.go:490` (the CLI), and 7 test sites — leaves the removed field unset, so `Stop`'s Details is byte-identical to before for every real invocation. There is no flag, config key, or JSON tag to retire alongside it (`grep -rn '\-\-reason'` outside `docs/` is empty), and `StopParams` is `internal/`, so there is no external consumer.
- **`watch.go`'s change really is comment-only.** `git diff c6b8127...HEAD -- internal/org/watch.go | grep -vE '^[+-]//'` yields no code lines, which matches the plan's central claim that the runtime path is untouched.
- **The new test genuinely discriminates, and the ordering trick is necessary.** Baseline is taken before the cutoff is appended, so with the guard the recount equals the baseline (no activity → deadman → one escalation), and without it the recount is one higher than an unchanged baseline (activity → the alert is deleted → zero escalations). Both of subtest (i)'s assertions (`*escalateCalls != 1` and `len(lines) != 1`) go red on removal. The note's counter-argument is correct too: computing the baseline after the cutoff would compare the identical function against the identical event set and could never exercise the guard.
- **The legacy Details prefix is faithful, not guessed.** `fakeWatchHerdr.PaneSendKeys` returns nil (`watch_test.go:80-85`), `fakeWatchAgmsg.Leave` returns nil (`:181-183`), and a seat spawned through `watchSpawnParams` records both `PaneID` and `AgmsgTeam` (`spawn.go:754-757`), so the pre-fix `Stop` produced exactly `pane=ok leave=ok` before appending its reason suffix — the string the fixtures hard-code.
- **The fixtures use the producer's own timestamp format and an established convention.** `clk.Now().UTC().Format(time.RFC3339)` is literally what `o.now()` computes (`spawn.go:146-152`), and direct `o.Manifest.Append` in tests is used at 13 other sites in this package, so the rewrite does not invent a new fixture idiom.
- **No coverage was dropped, and no assertion was weakened.** The `comm` set difference over `^func Test` shows two renames plus one new test; in the `SeatSentEvent` test only the seat-3 cutoff's *construction* changed, and its positive `sent` assertions are untouched. The manual-stop test now exercises the real, current `Stop` shape (no reason suffix at all), which is a closer match to what `ralph org stop` writes than the old `Reason: "operator: no longer needed"` literal was.
- **The renames are complete.** No reference to either old test name survives outside `docs/reports/` (historical) and the plan's own scope table; all three new names, and every other identifier the new comments cite, exist in the tree.
- **Register hygiene is correct.** The row keeps its 6-pipe shape, the closure marker is in the debt-item cell where `grep RESOLVED` finds it, the struck count moves 44 → 45, and `Impact` / `Why deferred` are left unstruck exactly as the sibling closed rows are. The note is specific about what was and was not done, including the commit (`bce892c`) and the reason the exclusion stayed.
