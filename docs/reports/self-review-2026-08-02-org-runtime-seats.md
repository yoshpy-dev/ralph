- **`parseHerdrEnvelope` fails closed in the right direction.** Non-JSON → fall back to trimmed raw (keeps `pane read` and test fakes working); `{`-prefixed but malformed → hard error rather than fallback, explicitly so a truncated envelope "never gets mistaken for a bare ID and fed downstream as e.g. a workspace_id". That is the precise failure mode the smoke test hit, and it is now structurally impossible.
- **AC-10's phantom-seat fix is in the right place.** `Stop` resolves the seat from the roster *before* the dry-run branch, so `--dry-run` cannot fabricate a `stopped` event either — a subtler variant that would have been easy to leave open.
- **`Send` fails closed and validates before the manifest append**, including in dry-run, and `--raw` bypasses are recorded as `raw=true` in Details rather than being invisible.
- **Test naming is exemplary** — `TestOrgStop_UnknownSeat_DryRun_AlsoErrorsWithoutAppendingEvent`, `TestOrgSpawn_AgentStart_NonBusyError_FailsImmediatelyWithoutRetry`, `TestValidate_BodySizeCap_CountsRunesNotBytes` all explain intent, not mechanics (`.claude/rules/testing.md`). No `t.Skip`, no debug prints, no commented-out code anywhere in the diff.

- **Mirror discipline held:** `.claude/rules/agent-messaging.md` and its `templates/base/` copy are byte-identical (same git blob) with matching modes; the three-surface `agmsg_home` lock-step is covered by the existing `defaults_sync_test.go` tripwire.
