## Positive notes

- `RALPH_ORG_PERMISSION_DEFAULT` is deliberately **not** added to `ralph-config.sh`'s export block, with a comment explaining why. This is exactly right: exporting it would have inverted the precedence for the Go env-first resolver, the trap that bit a previous PR.
- All four copies of the new skill (`.claude/`, `.agents/`, and both `templates/base/` mirrors) are byte-identical — verified with `diff -q`, all three comparisons clean.
- Both new fail-closed gates are genuinely closed, not advisory: `permissionArgsForDriver` rejects non-`guarded` codex seats with a loud, self-explaining error rather than emitting a stub argv, and the AC-2b `--scope` gate runs before the `DryRun` branch so dry runs are gated identically to real ones.
- The `herdr_agent_name` persistence is correctly `omitempty`-additive with a documented derive-fallback (`resolvedHerdrAgentName`), and `Wait`'s deliberate non-adoption is documented at the type, not buried in a test.
- `dryRunSpawn`'s two swallowed errors are now both propagated through the same `failStep` the real path uses, and the `absPath` test seam mirrors the existing `lookPath` precedent rather than inventing a new injection style.
- `withManifestLock` correctly separates the acquire-timeout error from `fn`'s own error, and `acquireFlock` polls `LOCK_EX|LOCK_NB` so the wait is bounded strictly by the context rather than by a blocking `flock(2)`.
- No secrets, credentials, debug statements, commented-out code, or `TODO`/`FIXME` markers anywhere in the +3949 lines.
- 61 new test functions; the tech-debt register rows are struck through with resolution provenance comments rather than deleted, preserving traceability.
- `syscall.Flock` is Linux/macOS-only, but the repo ships no Windows target (`.github/workflows/release.yml`), so this is not a live portability gap.
