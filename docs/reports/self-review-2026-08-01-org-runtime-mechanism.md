## Positive notes

- **No injection surface.** Every external call goes through `exec.CommandContext(ctx, name, args...)` with an argv slice — no shell, no string interpolation. The `--prompt` value is placed after a literal `--` separator (`herdr.go:39-42`) so a leading-dash prompt cannot be parsed as a flag. No secrets, credentials, `TODO`/`FIXME`, debug prints, `panic()`, or commented-out code anywhere in the new code.
- **Interfaces at the consumption site.** `HerdrClient`/`AgmsgClient` are declared in `internal/org` (`spawn.go:29-44`) rather than in `internal/org/driver`, keeping `internal/org` free of `exec` and matching `.claude/rules/golang.md`. The rationale is written down in the doc comment.
- **Manifest reads are failure-tolerant on purpose and it is documented:** missing file reads as empty, corrupt lines are counted and skipped rather than aborting, and the count is surfaced to the operator (`manifest.go:249-275`, `cli/org.go:419-421`) — `status` genuinely cannot be taken down by one bad line (AC-4's stated intent).
- **Roster ordering avoids a real trap:** "latest" is file/append order, not RFC3339 `TS` parsing, with the second-resolution tie ambiguity called out in the comment (`manifest.go:115-123`).
- **Compensation uses a fresh `context.Background()`** so best-effort cleanup is not cut short by the saga's already-expired deadline (`spawn.go:366-371`) — an easy detail to get wrong.
- **Config validation is strict and each rejection is a distinct, grep-able message** (`config.go` `[org]` block, `envelope.go:29-43`), and the "why absent keys never reach these checks" reasoning is written into the diff rather than left implicit.
- **Three-surface lock-step was actually wired,** not just asserted: `defaults_sync_test.go` gained seven `check(...)` calls with an explicit canonicalisation for the shell's array-less encoding. Both `templates/base/` mirrors are byte-identical (`cmp` exit 0).
