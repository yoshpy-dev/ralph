The `scopeChangeBodyBudget` naming collision was correctly left alone rather than renamed for grep hygiene.
- `pruneRetiredConditions` / `retiredConditionTypeFromAlertID` handle the parse edge cases defensively: an AlertID without `@` or without `/` returns `""`, which can never match `retiredConditionNames`, and the doc comment states that "leave it alone" is the deliberate safe default. `conditionKey`'s `org/seat/type` shape makes `LastIndex("/")` correct even when a seat id contains a separator-like character.
- The prune call is placed before `checkDeadman` with a comment explaining the ordering constraint, and the regression test hand-writes a genuinely legacy fixture — including the retired `"cutoff"` JSON field the current struct no longer declares — rather than round-tripping the current writer, so it actually exercises the upgrade path it claims to.
- The three `## 座席内 fan-out` sections are byte-identical in their normative bullets (`md5` of the section up to `例:` matches across implementer/reviewer/qa); only the illustrative examples differ per role. That is the right split.
- All four `/org` SKILL.md mirrors and both `ralph-config.sh` faces are byte-identical; the three-face model_pool change (Go `Default()` / `ralph.toml` / shell) moved in lockstep.
- `checkCodexModelSlugs` never spawns a process, dedupes pool entries before reporting a count, sorts for deterministic output, and maps a malformed cache to `info` rather than `warn` — a stale codex slug can never fail `ralph doctor`'s exit code, since only `fail` clears `allPass`.
