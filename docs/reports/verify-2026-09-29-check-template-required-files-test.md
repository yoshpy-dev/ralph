## Coverage gaps

- `./scripts/run-static-verify.sh`'s **default** invocation ran zero golang-specific checks in this worktree. Root cause: `scripts/detect-changed-languages.sh` prefers `@{upstream}` over `origin/main` when computing its diff base; this task worktree's branch (`test/check-template-required-files-test`) already has `origin/test/check-template-required-files-test` as its upstream, pointing at the same commit as HEAD (`fbcfb38`). `git merge-base HEAD @{upstream}` therefore equals HEAD, the diff is empty, and the script reports `scope=changed reason=no_changes`, selecting no language packs — even though this diff touches Go and shell files. This is an environment/tooling gap in the scope-detection script, not a defect in this plan's own changes: static Go analysis was still obtained via direct `gofmt`/`go vet` calls (both clean) and via `RALPH_VERIFY_BASE=main ./scripts/run-static-verify.sh`, which correctly falls back to `full` scope (an unclassified file, `scripts/check-template.sh`, forces the conservative fallback) and runs the golang verifier clean. Recommend the task lead treat any future `/verify` in an already-pushed task worktree as needing an explicit `RALPH_VERIFY_BASE=main` (or equivalent) override to get the wrapper's own language-scoped run, rather than trusting the default invocation's scope line.
