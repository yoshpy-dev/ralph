## Positive notes

- Path validation is genuinely applied at every boundary rather than declared and forgotten: `PlanCoreReplace` validates manifest keys *and* template-walk results, `RenderAdvisoryDiffs` validates before reading, `WriteUpgradeReport` validates before writing, and each has a negative test (`replaceplan_test.go:420`, `:432`, `advisory_test.go:125`, `report_test.go:151`). `cleanPathKey` additionally normalizes to forward slashes, which is what keeps the `io/fs` reads correct on a non-slash platform.
- The commit barrier is not just asserted in prose — `ApplyOps` structurally cannot touch the manifest, and `ManifestRefreshEntry` exists specifically so that re-planning over a half-applied tree reclassifies settled files instead of calling them drift. `TestPlanCoreReplace_ReplanAfterPartialFailureIsStable` pins exactly that.
- `block.go` earns its `rawLine` split: the round-trip (text + term) makes "every byte outside the markers is preserved" a property of the representation rather than a promise, and CRLF / no-trailing-newline / already-blank-line-at-EOF are each covered.
- `marshalJSONString` disabling HTML escaping is the right call for `Bash(a && b)` permission patterns, and the reason is written down at the call site.
- No debug statements, no commented-out code, no TODO/FIXME markers, no secrets, no U+FFFD, no trailing whitespace in the diff. The single `panic` (`settingsmerge.go:592`) is guarded by an invariant that is stated in the code.
- Errors are handled explicitly throughout; the only swallowed errors are `fs.ErrNotExist` / `os.ErrNotExist`, each converted into an explicit `has*` boolean that the caller must branch on.
- The out-of-scope `tests/test-gc-artifacts.sh` fix is correctly minimal, carries a comment explaining why the date must be relative, and is recorded as a deviation in the plan rather than slipped in silently.
