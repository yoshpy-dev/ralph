## Positive notes

- **The `Escalated` delete removal is provably behavior-preserving.** `pruneRetiredConditions`'s third loop (`internal/org/watch.go:573-577`) iterates every `Escalated` key under the identical predicate `retiredConditionNames[retiredConditionTypeFromAlertID(alertID)]`, and that predicate is a pure function of the key, so the deleted line could only ever remove entries the next loop also removes. No ordering or aliasing subtlety: the two maps are distinct fields of `watchStatusFile`.
- **The error-path fix removes a real footgun, not just a discarded error.** The base code, on `os.UserHomeDir` failure, fell through to `filepath.Join("", ".codex")` and returned the *relative* path `.codex/models_cache.json`, so doctor would silently read (or miss) a file under the operator's cwd. The new code returns an error before any path is built (`internal/cli/doctor_codex_models.go:34-38`).
- **The tightened assertions are genuinely tighter.** `strings.Count(out, wantWarn) != 1` (`internal/cli/org_test.go:673-675`) now actually checks the "exactly one fallback warning line" claim its own doc comment at `:639` makes. The fan-out assertions are section-scoped against a real boundary — all three seat templates place `max_seats`, `lead`, and `送ることは絶対に` between `## 座席内 fan-out` and `## レポート契約`.
