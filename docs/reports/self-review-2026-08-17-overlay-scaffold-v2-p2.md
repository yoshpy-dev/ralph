The `KNOWN_DIFFS` entry rename (`.claude/rules/model-routing.md` → `.claude/rules/ralph/model-routing.md`) tracked the move.
- **The `AGENTS.md` whole-file suppression was genuinely retired, not papered over.** `AGENTS.md` was removed from `KNOWN_DIFFS` and replaced with a block-aware comparison against `templates/base/.ralph/core/AGENTS.core.md`, and the tech-debt row was closed with an accurate description of what actually landed. `extract_agents_md_block` fails closed: a file with no markers yields empty output and diffs as DRIFTED against the non-empty source.
- **No skipped-file bug in the block reconciliation path.** `reconcileBlockSurfaces` keys off `result.Skipped`, and `RenderFS` populates `hashes[path]` at `render.go:71-72` *before* the skip branch at `:75-79`, so a pre-existing `AGENTS.md`/`.gitignore` still gets a manifest entry for step 3b's `SetFileOwned` call to attach the disk hash to. I specifically checked for the "disk hash computed but never recorded" failure mode and it does not occur.
- **The legacy-upgrade guard is placed correctly.** `internal/cli/upgrade.go`'s `LayoutV2` check sits before any diff computation or write and its comment accurately states that it applies to `--force` and `--dry-run` alike; `handleExistingProjectInit` closes the matching `ralph init`-on-existing-project entry point at both call sites.
- **`block.go`'s style parameterization preserved the old API honestly.** `UpdateManagedBlock`/`BeginMarker`/`EndMarker` are thin, correctly-documented delegations to the `*Styled` forms rather than reimplementations, and the marker scan uses the style-specific end marker throughout (no residual use of the HTML constant in the scan loop).
- **Test cleanup scope is safe.** `tests/test-ralph-dispatch.sh` confines every write and removal to a `mktemp -d` workdir, including the `run-verify.sh` fixture, so a parallel real session's `.harness/state/` is never touched.
- **No secrets, debug output, TODO/FIXME markers, or commented-out code** in the added lines (diff-wide grep).
