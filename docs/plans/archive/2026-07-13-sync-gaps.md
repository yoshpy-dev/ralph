# Plan: Close sync-surface gaps — generator, CI enforcement, lock-step tripwire

- Status: approved
- Flow: standard (/work)
- Branch: feat/sync-gaps
- Base: develop
- Date: 2026-07-13

## Objective

Reduce the cost and risk of ralph's mirror surfaces:

1. `.claude/skills/` ↔ `.agents/skills/` is maintained by hand; drift is caught
   by `check-skill-sync.sh` but that gate is manual-only (not in CI), despite
   `docs/quality/definition-of-done.md` requiring it.
2. The model-default 3-way lock-step (`scripts/ralph-config.sh` ↔ `ralph.toml`
   ↔ `internal/config/config.go Default()`) documented in
   `.claude/rules/model-routing.md` has no automated check, and neither does
   the reviewer-model default sync (`RALPH_CLAUDE_REVIEWER_MODEL` ↔
   `.claude/skills/cross-review/SKILL.md`).

## Scope

- New `scripts/sync-skills.sh`: regenerates `.agents/skills/` from
  `.claude/skills/` (drop Claude-only frontmatter keys, copy body and
  auxiliary files). Mirror maintenance becomes "edit `.claude/skills/`, run
  the generator". `check-skill-sync.sh` stays as the drift verifier.
- Round-trip proof: running the generator on the current tree produces zero
  diff against the committed `.agents/skills/`.
- CI: add `check-skill-sync.sh` to `.github/workflows/verify.yml`.
- New Go test `internal/config/defaults_sync_test.go`: parses
  `scripts/ralph-config.sh` (regex) and `ralph.toml` (existing parser),
  compares model/effort/per-phase defaults against `config.Default()`; also
  asserts the cross-review SKILL.md reviewer-model fallback matches
  `RALPH_CLAUDE_REVIEWER_MODEL`'s default.
- Shell test for the generator.
- Doc updates: definition-of-done (gate now CI-enforced), model-routing.md
  (lock-step now tripwired), skills README if one exists.
- Mirror any shared-script changes to `templates/base/` as check-sync requires.

## Non-goals

- No change to skill content or the mirror file format.
- No generation of `.codex/` surfaces (already covered by check-sync.sh).
- No removal of check-skill-sync.sh.

## Acceptance criteria

- AC1: `sync-skills.sh` regenerates `.agents/skills/` such that
  `git diff --exit-code .agents/skills` passes and `check-skill-sync.sh` passes.
- AC2: deleting a skill from `.claude/skills/` and regenerating removes it
  from `.agents/skills/` (inventory parity both directions).
- AC3: verify.yml runs check-skill-sync.sh; an induced drift fails CI locally.
- AC4: defaults_sync_test.go fails when any of the three surfaces (shell,
  toml, Go) disagree on a default, and when the cross-review SKILL.md
  reviewer fallback disagrees with ralph-config.sh.
- AC5: `./scripts/run-verify.sh`, `./scripts/check-sync.sh`,
  `./scripts/check-skill-sync.sh` all pass.

## Verify plan

- `bash tests/test-sync-skills.sh`
- `go test ./internal/config/... -count=1`
- `./scripts/check-skill-sync.sh && ./scripts/check-sync.sh && ./scripts/run-verify.sh`

## Risks

- R1: generator produces byte-different output than the hand-maintained
  mirror — mitigated by the round-trip AC; fix generator, not the mirror,
  unless the mirror itself is the drift.
- R2: regex parsing of ralph-config.sh is brittle — scope the regex to the
  documented `VAR="${VAR:-default}"` idiom and fail loudly on parse misses.
